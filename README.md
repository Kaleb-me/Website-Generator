# Website-Generator
A simple AI website generator

This is an AI website generator that will create a simple homepage for a website with a prompt from the user. Gemini creates the html which is then saved as a file to be viewed or edited.

HOW TO USE
- get a Gemini API key and include it in the generator script.
- Create a directory for index.html to be saved to (Python script needs to be updated to include directory)
- Change the prompt that gets sent to the LLM to satisfy any specific needs.
